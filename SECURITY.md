# Security policy

Maschinenlabor is a static, client-side web app. It has no backend, no accounts, no cookies and no analytics. The only network requests load fonts from Google Fonts. Settings (theme, language, last page) are stored in your browser's `localStorage` and never leave your device.

If you find a security problem anyway, for example script injection through a URL, please **do not open a public issue**. Report it privately via [GitHub's vulnerability reporting](https://github.com/fuchs-harry/electric-machines-model/security/advisories/new). I'll respond as soon as I can.

Only the latest version on `main` (the live demo) is supported.
